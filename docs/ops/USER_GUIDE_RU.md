# Руководство пользователя (кратко)

Язык интерфейса — русский. После установки войдите как супер-админ из `VBX_INSTALL_INFO.txt`.

## Вход

1. Откройте URL системы (из отчёта установки).
2. Логин или email + пароль → **Войти**.
3. Если включена 2FA — введите код из приложения-аутентификатора.
4. Смените пароль в **Профиль**, если вход с временным паролем.

Регистрация новых пользователей проходит через заявку; админ утверждает в **Настройки → Пользователи**.

## Поиск уязвимостей

1. Меню **Search**.
2. Запрос: `CVE-2024-…`, фрагмент описания, vendor/product, ID БДУ.
3. Фильтры: KEV, severity, источник.
4. Клик по строке → карточка CVE (CVSS, описания, KEV, блок БДУ, EPSS при наличии).

## Заявки (tickets)

1. Из карточки CVE/BDU — **Создать заявку**, либо раздел **Заявки** с `?cve=` / `?bdu=`.
2. Статусы: `new` → `in_progress` → `resolved` / `closed` (по RBAC).
3. Назначение исполнителя — роли ticket_manager / admin.
4. Комментарии и timeline на карточке заявки.

## Настройки (админ / sync)

| Раздел | Назначение |
|--------|------------|
| База данных | NVD API key, автообновление, sync NVD/KEV, загрузка XML БДУ |
| XDB | импорт exploits CSV/JSON |
| Уведомления | SMTP / предпочтения |
| Безопасность | 2FA policy, mTLS CA (для прокси), audit |
| Интеграции | внешние коннекторы |
| API keys | ключи для машинного доступа (`X-API-Key`) |

## Роли (кратко)

- **Viewer** — чтение поиска/карточек/дашборда  
- **Analyst** — плюс заявки, комментарии  
- **Admin / sync** — пользователи, синхронизации, настройки  

Подробности RBAC — в PRODUCT_SPEC; права выдаются через роли и группы.
